# Sample redraws

Replayable redraw scripts generated by `draw_with_code.py trace --codegen`
from vectorized images based on Sonia Kwek, the live model at the field:work
"Drawing with code" session (jo+kapi, 14 Nov 2026). Each script is self-contained: it replays its
strokes through the local API, so all you need is the driver:

1. `python3 fieldwork_server.py`
2. `python3 <script>.py`

Set `PACE_MS` near the top of a script above 0 to watch it draw at a slower,
human pace.
